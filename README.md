## Featured Projects

### 🎙️ [AI Voice Interviewer](https://github.com/ravishrana-dsai/AI-Showcase/tree/main/ai-voice-interviewer)
Full real-time voice interview pipeline. Candidate speaks, Deepgram transcribes, Claude responds, Cartesia synthesizes audio — all coordinated by Pipecat over Daily.co WebRTC. 20-minute structured interviews with 5-dimension scoring, no human required.

### 🤖 [Competitive Intelligence Agent](https://github.com/ravishrana-dsai/AI-Showcase/tree/main/competitive-intel-agent)
Autonomous multi-agent system. 8 parallel collectors scrape the web on a schedule. A master Claude agent uses tool-calling to dynamically decide which of 7 specialist processors to invoke. Delivers a weekly strategic brief to Slack automatically.

### 📣 [AI Marketing OS](https://github.com/ravishrana-dsai/AI-Showcase/tree/main/ai-marketing-os)
11-tab multi-agent marketing platform. Every approved output is analyzed by Claude Haiku, which extracts insights and stores them — future generations automatically get richer context. Real-time cost tracking per generation.

### 🧠 [HRBP AI Copilot](https://github.com/ravishrana-dsai/AI-Showcase/tree/main/hrbp-copilot)
Paste 1:1 meeting notes, get structured analysis: sentiment, concern level, risk flags with verbatim evidence, and longitudinal pattern detection across months of session history.

### 🗂️ [Talent Hub ATS](https://github.com/ravishrana-dsai/AI-Showcase/tree/main/talent-hub-ats)
Full-stack ATS with async AI resume screening (BullMQ + Claude), Kanban pipeline, interview scorecards, offer workflows, and a Turborepo monorepo. PostgreSQL + Redis + MinIO + Docker.
